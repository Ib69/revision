# Architecture des ordinateurs

Bienvenue dans la partie **Archi** — la **logique séquentielle** (B3).

Cette section couvre le programme du rattrapage :

- **Chapitre 1** : Logique séquentielle — les **bascules** (RS, D, JK)
- **Chapitre 2** : Les **compteurs** (asynchrones et synchrones)

---

## :material-lightbulb-on: Par où commencer ?

!!! tip "Lis ça en premier"
    Avant d'ouvrir le cours du prof, lis l'**[Introduction aux bascules](1_bascules/1_intro.md)**.

    Elle te donne **une image mentale unique** (la lampe à mémoire) qui marche pour **toutes** les bascules, plus les moyens mnémotechniques pour t'y retrouver. Ensuite le cours du prof te paraîtra évident.

---

## :material-target: Ce qui tombe à l'examen

L'examen B3 d'archi est **très prévisible**. Il y a toujours 4 exercices :

| Exo | Points | Ce qu'on te demande |
|---|---|---|
| **Ex 1** | ~7 pts | Compléter des **chronogrammes** (bascules + montages) |
| **Ex 2** | ~6 pts | Compteur synchrone **JK** : table de transition + Karnaugh |
| **Ex 3** | ~4 pts | Compteur synchrone **D** : table + Karnaugh |
| **Ex 4** | ~3 pts | Reconnaître / **câbler** un compteur asynchrone modulo m |

**Stratégie pour viser 13-14 :** sécuriser l'Ex 1 (chronogrammes) et l'Ex 4 (câblage) = **10 points "faciles"**, puis gratter sur les compteurs synchrones.
