# Mathématiques — Chapitre EFDP

**EFDP** = **E**nsembles, **F**onctions, **D**énombrement, **P**robabilités.

C'est le gros chapitre du semestre 2. Il est central : les ensembles servent partout (et notamment en info), le dénombrement est la base des probas, et les probas reviennent dans presque toutes les matières scientifiques.

## :material-target: Ordre conseillé de révision

1. **Ensembles** d'abord — c'est le langage. Sans le vocabulaire, le reste devient incompréhensible.
2. **Fonctions** ensuite — on réutilise direct les ensembles (domaine, image, etc.).
3. **Dénombrement** — applique les ensembles finis à des problèmes concrets de comptage.
4. **Probabilités** — applique tout ce qui précède (univers = ensemble, cas favorables = dénombrement).
5. **Examens blancs** pour vérifier que tout est en place.

!!! warning "Ne saute pas les parties"
    Les 4 parties s'enchaînent. Si tu galères en probas, c'est souvent parce que le dénombrement n'est pas net. Et si tu galères en dénombrement, c'est souvent parce que les ensembles ne sont pas nets.
